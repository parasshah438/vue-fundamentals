Webhook push

Send each prompt to n8n, Zapier, Make or your own API as JSON, so it can drive your workflows (post to Slack, save to Notion, run an agent).

Payload
{
  "prompt": "...",
  "tool": "ChatGPT",
  "category": "coding",
  "framework": "structured",
  "fields": { ... },
  "createdAt": "ISO date"
}

The browser sends a normal JSON POST, so the receiver must allow CORS (in n8n set Allowed Origins on the Webhook node). Otherwise trigger the webhook from your backend. Use HTTPS and a secret path.

Understand what you generate
How it works and which framework to use

    

      

        

          
The 4 steps

          
1
Describe the outcome
One sentence about what you want, not just a topic.

          
2
Auto-detect
Keyword rules choose category, tool style, format and tone. Everything stays editable.

          
3
Compose
A framework turns your fields into a structured prompt, or a compact one for image, video and music tools.

          
4
Check and use
See the quality checks, compare variations, optionally enhance with AI, then copy, save or send it onward.

        

      

      

        

          
Prompt frameworks at a glance

          

            

              
FrameworkPartsBest for

              
                
StructuredRole, Task, Context, Constraints, Output, RulesMost tasks; the safest default

                
CO-STARContext, Objective, Style, Tone, Audience, ResponseWriting and communication

                
RTCFRole, Task, Context, FormatQuick, compact prompts

                
RISENRole, Instructions, Steps, End goal, NarrowingMulti-step and process tasks

                
CRISPECapacity and Role, Insight, Statement, Personality, ExperimentBrainstorming; asks for alternatives

                
XML tags<role>, <task>, <context>, <constraints>...Claude and long, data-heavy prompts

                
JSON specMachine-readable fieldsPipelines, agents and APIs

              
            

          

          
Tips: be specific about the outcome, give context the AI cannot guess, set constraints and format, show an example when style matters, and always verify facts, code and numbers. Never paste passwords, keys or private data into a prompt.
