Why Ollama?

Your own local AI runtime.

Ollama lets you download and run large language models on your own computer. After downloading a model, local inference can work offline.

Cross-platform installation

Install Ollama on your operating system.

Choose your platform below and follow the installation steps. Ollama supports Windows, macOS, and Linux.

Windows 10 / 11
Install Ollama on Windows
  1. Visit the official Windows download page .
  2. Download OllamaSetup.exe.
  3. Run the installer.
  4. Click Install.
  5. Ollama will run in the background.
Download for Windows
Verify the installation

Open Command Prompt, PowerShell, or Windows Terminal: 

ollama --version
ollama list
Run your first model
# General-purpose model
ollama run qwen3:4b

# Lightweight alternative
ollama run gemma3:4b

# Coding model
ollama run qwen2.5-coder:1.5b
macOS
Install Ollama on macOS
  1. Visit the official macOS download page .
  2. Download the Ollama application.
  3. Open the downloaded file.
  4. Move Ollama to the Applications folder.
  5. Launch Ollama from Applications.
Download for macOS
Optional Homebrew installation

If Homebrew is installed, you can use: 

brew install --cask ollama

Launch Ollama, then open Terminal to verify it.

Verify and run a model
ollama --version

Linux
Install Ollama on Linux

Open a Terminal and run the official installation script: 

curl -fsSL https://ollama.com/install.sh | sh
Review any installation script before running it on your system.
Start the Ollama service

If your Linux distribution uses systemd and the Ollama service was installed, you can manage it with: 

sudo systemctl enable ollama
sudo systemctl start ollama
sudo systemctl status ollama

You can also start Ollama manually with:

ollama serve

Common commands on all platforms 

# List installed models
ollama list

# Download a model
ollama pull gemma3:4b

# Run a model
ollama run qwen3:4b

# Show running models
ollama ps

# Stop a model
ollama stop qwen3:4b

# Remove a model
ollama rm qwen3:4b

# Download an embedding model
ollama pull nomic-embed-text:latest

Model selection

Pick the right model for the job.

Smaller models are usually better for autocomplete and devices with limited memory. Larger models may provide stronger answers but require more RAM.

Purpose Recommended model Approximate size Best for
General chat qwen3:4b Small to medium Chat, explanations, daily tasks
Coding qwen3:4b Small to medium Laravel, React, Next.js, Node.js
Autocomplete qwen2.5-coder:1.5b Lightweight Fast inline code completion
Alternative chat gemma3:4b Small to medium General-purpose local AI
Embeddings nomic-embed-text:latest Lightweight Search, RAG, document indexing
Hardware guide

Choose models your device can handle.

Ollama works with CPU-only systems, although a compatible dedicated GPU can significantly improve performance.

System RAM Recommended models
8 GB Gemma3 4B, Qwen3 4B
16 GB Qwen3 4B or 8B, depending on free memory
32 GB+ Larger 14B or higher models
On a device with 16 GB RAM and integrated graphics, avoid very large 12B+ models for everyday development. They may be slow and leave too little memory for the operating system and development tools.

Client app
  1. Keep Ollama running on your computer.
  2. Connect the computer and phone to the same Wi-Fi network.
  3. Configure the app with your computer's local IP address.
  4. Allow the connection through your operating system firewall if required.
Security: Do not expose Ollama directly to the public internet. Use a trusted local network or a secure VPN, and add authentication through a suitable proxy if remote access is required.
Application API

Call Ollama from your own app.

Ollama provides a local HTTP API. This example uses the native /api/chat endpoint. 

fetch("http://localhost:11434/api/chat", {
  method: "POST",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    model: "qwen3:4b",
    messages: [
      {
        role: "user",
        content: "Explain dependency injection in Laravel."
      }
    ],
    stream: false
  })
})
  .then(response => response.json())
  .then(data => console.log(data.message.content))
  .catch(error => console.error(error));
Never include OpenRouter, OpenAI, or any other cloud API key in public frontend code. Store secrets in environment variables and use a backend server. If a key has already been shared publicly, revoke it immediately.

Recommended practices

Keep your local AI stack reliable.

Use lightweight coding models for fast inline completion and reserve larger models for chat, debugging, and architecture questions.

Download only the models you use regularly. Check them with ollama list and remove unused models with ollama rm model-name.

Keep Ollama on localhost whenever possible. For mobile access, use a trusted Wi-Fi network or VPN and avoid public exposure.

Update Ollama periodically to benefit from bug fixes, model compatibility improvements, and new features.
