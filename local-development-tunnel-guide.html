01 — Overview

What Is Localtunnel?

Localtunnel creates a public URL that forwards traffic to your local application.

Public Internet
↓
your-app.loca.lt
↓
Localtunnel
↓
localhost:PORT
↓
Your Application

Localtunnel works with almost any HTTP application, including:

Next.js Laravel React Vue Angular Node.js PHP WordPress Django APIs
02 — Installation

Install Localtunnel

Requirements
  • Node.js
  • npm

Check that Node.js and npm are installed:

node -v
npm -v

Install Localtunnel globally:

npm install -g localtunnel

Verify the installation:

lt --version
03 — First Tunnel

Basic Localtunnel Command

Use the following format:

lt --port PORT_NUMBER

Example:

lt --port 3000

Localtunnel will return a public URL similar to:

your url is:
https://random-name.loca.lt
Open the generated HTTPS URL in your browser.
04 — Branding

Custom Localtunnel Subdomain

Use this format:

lt --port PORT --subdomain NAME

Example:

lt --port 3000 --subdomain myapp

Your public URL will be:

https://myapp.loca.lt
A custom subdomain may be unavailable if another user is already using it.

Laravel Fix

Laravel HTTPS Form Warning Fix

You may see this warning:

The information that you’re about to submit is not secure

Laravel may generate HTTP URLs while Localtunnel uses HTTPS. Update your Laravel configuration to use the tunnel URL.

Update `.env`
APP_URL=https://laravelapp.loca.lt
Clear Laravel Cache
php artisan config:clear
php artisan cache:clear
Force HTTPS

Open:

app/Providers/AppServiceProvider.php

Add the import:

use Illuminate\Support\Facades\URL;

Update the boot() method:

public function boot(): void
{
    URL::forceScheme('https');
}

Finally, clear the optimization cache:

php artisan optimize:clear

You can run multiple tunnels at the same time, each pointing to a different local port.

lt --port 3000 --subdomain nextapp

lt --port 8000 --subdomain laravelapp

# API
lt --port 5000 --subdomain api
16 — Domains

Custom Domain Information

Localtunnel supports subdomains under:

yourname.loca.lt

Example:

laravelapp.loca.lt

It does not normally provide arbitrary domains such as:

app.yourdomain.com

For a real custom domain, consider:

  • Cloudflare Tunnel
  • ngrok with a custom domain
  • A VPS with Nginx
  • Another reverse-proxy service
17 — Databases

Database Information

Localtunnel exposes HTTP applications. It does not directly expose database services.

Works with Localtunnel
  • Laravel
  • Next.js
  • React
  • Vue
  • Angular
  • APIs
  • WordPress
  • PHP
  • Django
Not Directly Supported
  • MySQL
  • PostgreSQL
  • MongoDB
  • Redis

Database access generally requires:

  • SSH tunneling
  • A VPN
  • A hosted database
  • A database-specific secure access solution
18 — Support

Troubleshooting

Check the Local Application First

Verify that your application works locally before creating the tunnel.

Application Local URL
Next.jshttp://localhost:3000
Laravelhttp://localhost:8000
Reacthttp://localhost:5173
If the application does not work locally, the tunnel will not work either.
Use the HTTPS URL

Use:

https://app-name.loca.lt

Avoid:

http://app-name.loca.lt
Confirm the Port

The port passed to Localtunnel must match the port used by your application. 

# Application runs on port 8000
lt --port 8000
Keep Both Terminals Running
  • Terminal 1: Run the application
  • Terminal 2: Run Localtunnel
